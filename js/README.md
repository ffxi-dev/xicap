# @xicap/wasm

WebAssembly reader for [xicap](../README.md) packet captures. The full xicap C++
library is compiled to wasm via Emscripten + Embind, so reader behaviour is
byte-for-byte identical to the native build.

## Install

```
npm install @xicap/wasm
```

## Usage

```ts
import { Reader, PacketDirection, XicapError, ErrorCode } from "@xicap/wasm";

const bytes = await fetch("./session.xicap").then(r => r.arrayBuffer());

try {
    const reader = await Reader.open(bytes);
    console.log(reader.clientVersion, reader.startTimestampMs);

    for (const pkt of reader) {
        if (pkt.direction === PacketDirection.ServerToClient) {
            // pkt.opcode, pkt.timestampMs, pkt.data: Uint8Array, pkt.markers: string[]
        }
    }

    reader.close();  // wasm objects don't GC; call close() when done
} catch (e) {
    if (e instanceof XicapError) {
        if (e.code === ErrorCode.DictionaryMismatch) {
            // capture was compressed with a different dictionary
        }
    }
    throw e;
}
```

## Notes

* Bundle size: ~300-400 KB wasm (xicap + zstd + the trained dictionary baked in)
  plus ~10 KB of JS shim. The dictionary doesn't ship as a separate file.
* The whole input file is held in wasm memory (via MEMFS). Grow-as-needed
  heap is enabled.
* `Reader` is read-only. Writing captures from JS is not supported in this
  package.
* `pkt.data` is a fresh `Uint8Array` per call — safe to retain. Other accessors
  that return wasm-owned bytes (`getExtension`) document their lifetime
  individually.

## Build from source

Requires emsdk and ninja on PATH (or set `EMSDK` and `NINJA` env vars). On
Windows where MSVC bundles its own ninja, point `NINJA` at it:

```
export EMSDK=~/emsdk
export NINJA=ninja            # or full path; CI uses just `ninja` on PATH
npm run build                 # produces dist/xicap.wasm + dist/xicap.js + dist/index.js
npm test
```

The Node test reads `test/fixtures/sample.xicap`, generated by the C++
`xicap_make_fixture` tool:

```
cmake -S .. -B ../build -G Ninja -DXICAP_BUILD_FIXTURE_TOOL=ON
cmake --build ../build --target xicap_make_fixture
mkdir -p test/fixtures
../build/xicap_make_fixture test/fixtures/sample.xicap
```
